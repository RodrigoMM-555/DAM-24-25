Cada elemento HTML puede ser accedido mediante selectores, ya sea por su id, etiqueta o cualquier otro atributo, y su contenido puede leerse o modificarse de distintas maneras, como usando textContent para texto puro o innerHTML para contenido que incluya etiquetas HTML. Comprender estos conceptos es esencial para crear páginas dinámicas, donde los elementos pueden actualizarse en tiempo real según las acciones del usuario o la información disponible en arrays y estructuras de datos.

En los ejemplos proporcionados se observan distintos enfoques. En este se seleccionan elementos por su id y se modifica su contenido textual con textContent, asegurando que solo se cambie el texto sin afectar posibles etiquetas HTML internas:
``
document.querySelector("#rojo").textContent = "texto rojo";
document.querySelector("#verde").textContent = "texto verde";
document.querySelector("#azul").textContent = "texto azul";
``

En este otro se trabaja con la selección por etiqueta. Se obtiene un párrafo mediante querySelector("p") y se accede a su contenido con textContent. Esto permite leer el texto que contiene el elemento y, por ejemplo, mostrarlo en la consola o utilizarlo en otras partes del script:
``
const elemento = document.querySelector("p");
console.log(elemento.textContent);
``

ta,bien podemos ver la combinación de arrays e innerHTML para generar contenido dinámico. Cada artículo del array se recorre en un bucle for y se inserta como un elemento < h3> dentro del contenedor < main>, mostrando cómo actualizar el DOM de manera iterativa:
``
const articulos = ["Primer artículo","Segundo artículo","Tercer artículo"];
const contenedor = document.querySelector("main");
for(let i = 0; i < articulos.length; i++){
    contenedor.innerHTML += "<h3>" + articulos[i] + "</h3>";
}
``

Finalmente, se ejemplifica la creación dinámica de elementos HTML completos dentro de un < div>. Usando innerHTML, se añade un encabezado < h1> al div seleccionado, demostrando la flexibilidad para generar contenido estructurado directamente desde JavaScript:
``
document.querySelector("div").innerHTML = "<h1>Hola</h1>";
``

En conclusión, dominar la selección y manipulación de elementos del DOM permite construir interfaces web interactivas y dinámicas, donde se puede actualizar texto, agregar contenido estructurado y generar páginas que respondan a la interacción del usuario. Los conocimientos adquiridos aquí son aplicables en futuros proyectos como blogs dinámicos, paneles de administración, sistemas de comentarios o cualquier aplicación web que requiera actualizar su contenido sin recargar la página.
