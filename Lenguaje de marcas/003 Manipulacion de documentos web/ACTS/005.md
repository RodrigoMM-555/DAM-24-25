El estilo condicional, las funciones de cálculo en CSS y la manipulación de clases con JavaScript permiten que una página web reaccione dinámicamente tanto a la interacción del usuario como al tamaño del contenedor o al estado de los elementos. Estos conceptos se apoyan en el uso de clases CSS para aplicar estilos, en funciones como calc() para realizar operaciones matemáticas directamente en hojas de estilo y en JavaScript para añadir, quitar o alternar clases en función de condiciones concretas, como la longitud de un texto o un evento de clic.

Para aplicar estilo condicional a un campo de entrada, se puede escuchar el evento que se dispara cada vez que el usuario pulsa una tecla. A partir del valor introducido, se calcula su longitud y se añaden o eliminan clases CSS según se cumpla o no la condición establecida, consiguiendo una respuesta visual inmediata.
``
<input class="rojo">

<script>
let entrada = document.querySelector("input");
entrada.onkeyup = function(){
    let longitud = this.value.length;
    if(longitud === 9){
        this.classList.add("verde");
        this.classList.remove("rojo");
    }else{
        this.classList.remove("verde");
        this.classList.add("rojo");
    }
}
</script>
``

Las funciones de cálculo en CSS permiten definir tamaños flexibles combinando porcentajes y valores fijos. Mediante calc(), el navegador realiza operaciones matemáticas que facilitan diseños adaptables sin necesidad de JavaScript, logrando que los elementos se ajusten mejor a distintos tamaños de pantalla.
``
div{
    width: calc(50% + 100px);
    background: red;
}
``

La manipulación de clases con JavaScript facilita cambiar el aspecto de un elemento en función de una acción del usuario, como un clic. Alternar clases permite reutilizar estilos definidos en CSS y mantener el código más limpio y organizado.
``
<p id="texto">Esto es un párrafo</p>
<button id="cambiar">Cambiar color</button>

<script>
let parrafo = document.querySelector("#texto");
let boton = document.querySelector("#cambiar");

boton.onclick = function(){
    if(parrafo.classList.contains("rojo")){
        parrafo.classList.remove("rojo");
        parrafo.classList.add("verde");
    }else{
        parrafo.classList.remove("verde");
        parrafo.classList.add("rojo");
    }
}
</script>
``

En conclusión, el uso combinado de estilos condicionales, cálculos en CSS y manipulación de clases con JavaScript es clave para desarrollar interfaces modernas y dinámicas, y puede aplicarse en futuros proyectos como formularios con validación visual en tiempo real, diseños web adaptativos, paneles interactivos o aplicaciones donde la experiencia del usuario mejore gracias a respuestas visuales claras e inmediatas.
