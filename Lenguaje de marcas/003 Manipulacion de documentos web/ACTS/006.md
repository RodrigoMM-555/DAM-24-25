La publicación web en GitHub Pages se basa en comprender cómo funciona un repositorio como alojamiento de archivos estáticos y cómo GitHub puede servir esos archivos directamente como una página web accesible desde Internet. Los elementos principales de este proceso son la creación de repositorios públicos, la correcta organización de los archivos (especialmente el archivo index.html), la configuración del branch desde el que se publicará el contenido y la relación entre el desarrollo web y la proyección profesional mediante plataformas como LinkedIn.

Para empezar, se crea un repositorio público llamado curriculum, ya que GitHub Pages solo funciona con repositorios públicos. Dentro de este repositorio, el archivo clave es index.html, que será el punto de entrada de la web. Este archivo debe situarse en la raíz del repositorio y contener una estructura HTML básica que el navegador pueda interpretar correctamente.
``
<!doctype html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <title>Currículum</title>
</head>
<body>
    <h1>Mi currículum</h1>
    <p>Bienvenido a mi página personal publicada con GitHub Pages.</p>
</body>
</html>
``

Una vez añadido el contenido y subido al repositorio, se configura GitHub Pages desde la sección de configuración. Al seleccionar el branch principal (main o master) como fuente, GitHub utiliza automáticamente el archivo index.html para generar la página web. Tras unos minutos de procesamiento, se obtiene una URL pública donde el contenido ya es visible online.

El mismo procedimiento se puede repetir para un segundo repositorio que podria ser un portafolio para mostrar proyectos, prácticas o trabajos realizados durante el curso. Separar el currículum del portafolio permite organizar mejor la información y presentar una imagen más profesional, mostrando tanto los datos personales como las habilidades técnicas mediante ejemplos reales.

En conclusión, la publicación de páginas web con GitHub Pages es una base sólida para futuros proyectos profesionales, ya que permite crear currículums online, portafolios interactivos y páginas personales accesibles desde cualquier lugar, integrándolos fácilmente con redes profesionales y procesos de selección, y sentando las bases para desarrollos web más avanzados en el futuro.
