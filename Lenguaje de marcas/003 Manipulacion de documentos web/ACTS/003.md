La manipulación de eventos y la creación dinámica de elementos en JavaScript se centra en la interacción con el DOM, permitiendo que la página responda a acciones del usuario y que el contenido se genere o modifique en tiempo real. Entre los conceptos principales destacan la creación de elementos con createElement, la adición de contenido con textContent o innerHTML, la captura de eventos mediante onclick u otros manejadores, y la lectura de datos desde archivos JSON para poblar elementos de forma automática. Dominar estas técnicas es fundamental para construir interfaces interactivas y dinámicas que no necesiten recargar la página para actualizar la información.

Para crear varios botones de forma dinámica, se recorre un array con los nombres de los botones y se genera un elemento < button> por cada valor. Cada botón se añade a un contenedor existente en la página y puede asociarse con un evento click para detectar la interacción del usuario:
``
let botones = ['clientes','productos','pedidos'];
let contenedor = document.querySelector("nav");
botones.forEach(function(texto_boton){
    let boton = document.createElement("button");
    boton.textContent = texto_boton;
    contenedor.appendChild(boton);
    
    // Evento click que indica qué botón se ha pulsado
    boton.onclick = function(){
        console.log(`Has hecho click en el botón ${texto_boton}`);
    }
});
``

Para consumir datos desde un archivo JSON, se utiliza la función fetch para obtener el contenido y transformarlo en un objeto JavaScript. Esto permite manejar información externa de forma estructurada y mostrarla en la consola o usarla en la página:
``
fetch("botones.json")
.then(function(respuesta){
    return respuesta.json();
})
.then(function(datos){
    console.log(datos);
});
``

La información obtenida de un JSON también puede servir para poblar tablas de manera dinámica. Cada línea del JSON se convierte en una fila de la tabla y cada elemento en una celda, creando contenido estructurado automáticamente:
``
fetch("tabla.json")
.then(function(respuesta){
    return respuesta.json();
})
.then(function(datos){
    let contenedor = document.querySelector("body");
    let tabla = document.createElement("table");
    contenedor.appendChild(tabla); 
    datos.forEach(function(linea){
        let fila = document.createElement("tr");
        linea.forEach(function(celda){
            let data = document.createElement("td");
            data.textContent = celda;
            fila.appendChild(data);
        });
        tabla.appendChild(fila);
    });
});
``

Además, la creación de una interfaz base con un menú lateral y un contenedor principal permite distribuir el espacio de la página de manera clara y proporcionar un marco sobre el que insertar elementos dinámicos, mejorando la organización visual de la información:
``
<nav>Menú lateral</nav>
<main>Contenido principal</main>
``

En conclusión, dominar la creación de elementos dinámicos, la captura de eventos y la lectura de datos JSON permite construir aplicaciones web interactivas como menús dinámicos, paneles de control, blogs o sistemas de gestión de información, donde la interfaz se actualiza automáticamente según los datos disponibles y las acciones del usuario, sin necesidad de recargar la página.
