En este ejercicio partimos de una situación cotidiana dentro de la escuela, donde una misma persona puede compartir características básicas pero desempeñar roles distintos, igual que alguien puede disfrutar de los videojuegos, programar o entrenar en el gimnasio según el momento. Esta idea encaja perfectamente con la programación orientada a objetos, donde la herencia y el polimorfismo permiten reutilizar una base común y adaptar el comportamiento según el tipo de objeto.

Para comenzar, se define una clase general llamada Persona. Esta clase representa el punto de partida del sistema y contiene únicamente la información que todas las personas comparten: el nombre y los apellidos. Además, se incluye un método dameDatos() que devuelve el nombre completo, método que más adelante será modificado en las clases hijas.
``
class Persona:
    def __init__(self, nombre, apellidos):
        self.nombre = nombre
        self.apellidos = apellidos

    def dameDatos(self):
        return self.nombre + " " + self.apellidos
``

A partir de esta base, se construye la clase Profesor, que hereda directamente de Persona. Aunque mantiene los mismos atributos, el método dameDatos() se redefine para reflejar su rol dentro de la escuela, añadiendo el prefijo “Profesor:”. Esto ilustra cómo un mismo método puede comportarse de forma distinta dependiendo del tipo de objeto, algo muy común también en el desarrollo de videojuegos o aplicaciones.
``
class Profesor(Persona):
    def __init__(self, nombre, apellidos):
        super().__init__(nombre, apellidos)

    def dameDatos(self):
        return "Profesor: " + self.nombre + " " + self.apellidos
``

De manera similar, se crea la clase Alumno, que también hereda de Persona pero añade un nuevo atributo, el email. En este caso, el método dameDatos() se sobrescribe para incluir esta información adicional, demostrando cómo cada clase puede ampliar o adaptar el comportamiento heredado según sus necesidades.
``
class Alumno(Persona):
    def __init__(self, nombre, apellidos, email):
        super().__init__(nombre, apellidos)
        self.email = email

    def dameDatos(self):
        return self.nombre + " " + self.apellidos + " - Email: " + self.email
``

Finalmente, se ponen en práctica las clases creando un objeto alumno y un objeto profesor con los datos indicados. Al llamar al mismo método dameDatos() sobre ambos objetos, se obtienen resultados diferentes, lo que confirma el uso correcto del polimorfismo en el programa.
``
alumno1 = Alumno("Jose Vicente", "Carratala", "jose@email.com")
profesor1 = Profesor("Juan", "Garcia")

print(alumno1.dameDatos())
print(profesor1.dameDatos())
``

En conclusion, con este ejercicio se refuerza la idea central de la unidad: usar la herencia para compartir código y el polimorfismo para adaptar comportamientos segun la clase. Estos conceptos son clave en entornos reales de programación, ya sea al crear sistemas de gestión escolar, aplicaciones profesionales o incluso videojuegos, donde una misma base puede dar lugar a múltiples comportamientos según el contexto.
