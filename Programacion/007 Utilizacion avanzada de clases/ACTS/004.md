La práctica tiene como objetivo entender cómo rotar objetos en 2D usando JavaScript y CSS, aplicando trigonometría para actualizar dinámicamente la posición de las manecillas de un reloj. Se busca reforzar la programación orientada a eventos y animación en tiempo real, mientras se aplican buenas prácticas como separar cada manecilla en su propio canvas para simplificar el redibujo.

Para empezar debemos construir el HTML, que sirve como soporte para dibujar el reloj. Se crean varios < canvas> para diferenciar el círculo central y las manecillas de horas, minutos y segundos. Separar cada manecilla en su propio canvas permite actualizar solo la parte necesaria sin redibujar todo, evitando así errores visuales comunes como que las líneas se acumulen sobre el lienzo anterior.
``
<!doctype html>
<html>
  <head>
    <style>
      body{
        margin:0;
        overflow:hidden;
      }
      #reloj {
        position: relative;
        width: 500px;
        height: 500px;
      }
      canvas {
        position: absolute;
        left: 0;
        top: 0;
      }
    </style>
  </head>
  <body>
    <div id="reloj">
      <canvas id="circuloCentral" width="500" height="500"></canvas>
      <canvas id="horas" width="500" height="500"></canvas>
      <canvas id="minutos" width="500" height="500"></canvas>
      <canvas id="segundos" width="500" height="500"></canvas>
    </div>
    <script src="rotacion.js"></script>
    <script>
      bucle();
    </script>
  </body>
</html>
``

En el archivo rotacion.js se implementa la función bucle(), que obtiene la hora actual y convierte cada unidad de tiempo en un ángulo usando trigonometría. Cada manecilla se dibuja sobre su propio canvas, lo que simplifica la actualización y evita problemas frecuentes como dibujar sobre la manecilla anterior sin limpiar el canvas primero. Esta técnica es especialmente útil para animaciones en tiempo real y demuestra una buena práctica de programación al mantener cada elemento modularizado.
``
let temporizador = null;

function bucle(){
  let fecha = new Date();
  let hora = fecha.getHours() % 12;
  let minuto = fecha.getMinutes();
  let segundo = fecha.getSeconds();

  const centroX = 250;
  const centroY = 250;

  // Función para borrar un canvas antes de dibujar
  function limpiarCanvas(id) {
    let ctx = document.getElementById(id).getContext("2d");
    ctx.clearRect(0, 0, 500, 500);
    return ctx;
  }

  // Dibuja el círculo central
  let ctxCentral = limpiarCanvas("circuloCentral");
  ctxCentral.lineWidth = 5;
  ctxCentral.strokeStyle = "black";
  ctxCentral.beginPath();
  ctxCentral.arc(centroX, centroY, 200, 0, Math.PI * 2);
  ctxCentral.stroke();
``

Luego, se dibujan las manecillas. La manecilla de horas utiliza la fórmula ((hora + minuto/60) * Math.PI * 2 / 12 - Math.PI/2) para calcular la rotación correcta. Es importante restar Math.PI/2 para alinear la manecilla con la posición vertical, ya que un error común es olvidarlo, lo que hace que las manecillas comiencen desde la dirección incorrecta.
``
  // Manecilla de horas
  let ctxHoras = limpiarCanvas("horas");
  let anguloHoras = ((hora + minuto/60) * Math.PI * 2) / 12 - Math.PI/2;
  ctxHoras.lineWidth = 10;
  ctxHoras.strokeStyle = "black";
  ctxHoras.beginPath();
  ctxHoras.moveTo(centroX, centroY);
  ctxHoras.lineTo(
    centroX + Math.cos(anguloHoras) * 120,
    centroY + Math.sin(anguloHoras) * 120
  );
  ctxHoras.stroke();

  // Manecilla de minutos
  let ctxMinutos = limpiarCanvas("minutos");
  let anguloMinutos = (minuto * Math.PI * 2) / 60 - Math.PI/2;
  ctxMinutos.lineWidth = 6;
  ctxMinutos.strokeStyle = "green";
  ctxMinutos.beginPath();
  ctxMinutos.moveTo(centroX, centroY);
  ctxMinutos.lineTo(
    centroX + Math.cos(anguloMinutos) * 160,
    centroY + Math.sin(anguloMinutos) * 160
  );
  ctxMinutos.stroke();
``

Finalmente, la manecilla de segundos se dibuja de manera similar, usando un color distinto para facilitar la visualización. Limpiar el canvas antes de dibujar cada manecilla evita que queden restos de la posición anterior, una práctica recomendable en cualquier animación que dependa del tiempo.
``
  // Manecilla de segundos
  let ctxSegundos = limpiarCanvas("segundos");
  let anguloSegundos = (segundo * Math.PI * 2) / 60 - Math.PI/2;
  ctxSegundos.lineWidth = 2;
  ctxSegundos.strokeStyle = "red";
  ctxSegundos.beginPath();
  ctxSegundos.moveTo(centroX, centroY);
  ctxSegundos.lineTo(
    centroX + Math.cos(anguloSegundos) * 180,
    centroY + Math.sin(anguloSegundos) * 180
  );
  ctxSegundos.stroke();

  // Llamada recursiva cada segundo
  clearTimeout(temporizador);
  temporizador = setTimeout(bucle, 1000);
}
``

En conclusion, separar los elementos y limpiar el canvas antes de redibujar mejora el rendimiento y evita errores visuales comunes. Como mejora futura, se podría añadir interpolación para animaciones más suaves, números en el reloj o expandir la lógica para otros gráficos interactivos, mostrando cómo esta técnica sirve como base para proyectos más complejos.
