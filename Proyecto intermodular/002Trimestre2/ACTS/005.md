En este ejercicio se desarrolla un blog funcional utilizando PHP y MySQL, integrando base de datos, control de usuarios y generación dinámica de contenido HTML. La práctica sirve para consolidar cómo se conectan aplicaciones web en PHP con una base de datos relacional y cómo se muestran datos reales en una interfaz sencilla pero clara.

La creación de la base de datos establece la estructura mínima necesaria para almacenar artículos de un blog. Definir correctamente los tipos de datos y usar un juego de caracteres adecuado como utf8mb4 permite evitar problemas con acentos o caracteres especiales. Además, el uso de una clave primaria autoincremental facilita la identificación única de cada artículo.
``
CREATE DATABASE IF NOT EXISTS blogphp
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE blogphp;

CREATE TABLE IF NOT EXISTS blog (
  id INT AUTO_INCREMENT PRIMARY KEY,
  titulo VARCHAR(255) NOT NULL,
  fecha DATETIME NOT NULL,
  autor VARCHAR(100),
  contenido TEXT NOT NULL
);

INSERT INTO blog (titulo, fecha, autor, contenido)
VALUES 
('Artículo 1', NOW(), 'Jose Vicente Carratala', 'Contenido del artículo 1'),
('Artículo 2', NOW(), 'Jose Vicente Carratala', 'Contenido del artículo 2');


La creación de un usuario específico para la base de datos ayuda a mejorar la seguridad del sistema, evitando el uso del usuario root en aplicaciones web. Asignar permisos únicamente sobre la base de datos necesaria reduce riesgos en caso de fallos o accesos indebidos.

CREATE USER 
'blogphp'@'localhost' 
IDENTIFIED BY 'Blogphp123$';

GRANT USAGE ON *.* TO 'blogphp'@'localhost';

ALTER USER 'blogphp'@'localhost' 
REQUIRE NONE 
WITH MAX_QUERIES_PER_HOUR 0 
MAX_CONNECTIONS_PER_HOUR 0 
MAX_UPDATES_PER_HOUR 0 
MAX_USER_CONNECTIONS 0;

GRANT ALL PRIVILEGES ON blogphp.* 
TO 'blogphp'@'localhost';

FLUSH PRIVILEGES;
``

El archivo de conexión centraliza las credenciales y la lógica de acceso a la base de datos. Separar la conexión en un archivo independiente facilita el mantenimiento y evita repetir código en múltiples páginas. También permite cambiar credenciales en un solo lugar si fuera necesario.
``
<?php

$host = "localhost";
$user = "blogphp";
$pass = "Blogphp123$";
$db   = "blogphp";

$conexion = new mysqli($host, $user, $pass, $db);

if ($conexion->connect_error) {
    die("Conexión fallida: " . $conexion->connect_error);
}

?>
``

El archivo principal del blog combina HTML y PHP para mostrar los artículos almacenados en la base de datos. El uso de estilos CSS integrados mejora la presentación visual sin complicar el ejercicio. Además, aplicar htmlspecialchars() al mostrar los datos ayuda a evitar problemas de seguridad y errores de visualización si el contenido incluye caracteres especiales.
``
<!doctype html>
<html>
<head>
    <style>
        body, html {
            font-family: sans-serif;
        }
        header, main, footer {
            width: 800px;
            margin: auto;
            padding: 20px;
        }
        article {
            border-bottom: 1px solid #ccc;
            margin-bottom: 20px;
        }
    </style>
</head>
<body>
    <header>
        <h1>Jose Vicente Carratala</h1>
        <h2>Blog superinteresante</h2>
    </header>
    <main>
        <?php
            include 'conectar.php';

            $sql = "SELECT * FROM blog";
            $resultado = $conexion->query($sql);

            while ($fila = $resultado->fetch_assoc()) {
                echo '
                    <article>
                        <h3>' . htmlspecialchars($fila['titulo']) . '</h3>
                        <time>' . htmlspecialchars($fila['fecha']) . '</time>
                        <p>' . htmlspecialchars($fila['autor']) . '</p>
                        <p>' . htmlspecialchars($fila['contenido']) . '</p>
                    </article>
                ';
            }

            $conexion->close();
        ?>
    </main>
    <footer>
    </footer>
</body>
</html>
``

La prueba final del blog consiste en acceder al archivo blog.php desde el navegador y comprobar que los artículos se muestran correctamente. Si algo no funciona como se espera, revisar el archivo de errores de Apache suele dar pistas claras sobre problemas de conexión, rutas incorrectas o errores de sintaxis en PHP.

Para cerrar la actividad, este ejercicio demuestra cómo unir base de datos, PHP y HTML para crear una aplicación web dinámica desde cero. Lo aprendido puede ampliarse fácilmente en el futuro añadiendo formularios para crear artículos, sistemas de autenticación, paneles de administración o estilos más avanzados, sentando las bases para proyectos web más completos y profesionales.
