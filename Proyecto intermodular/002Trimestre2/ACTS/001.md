En esta actividad se trabaja la conexión entre Python y MySQL, aprendiendo a establecer una conexión correcta, realizar consultas SQL, ordenar resultados y manejar los datos devueltos tanto en listas como de diccionarios. Estos pasos son fundamentales para entender cómo interactuar con bases de datos desde Python de forma estructurada y segura.

La conexión a la base de datos permite comprobar que el usuario y los permisos están correctamente configurados. Una buena práctica importante es cerrar siempre el cursor y la conexión al finalizar, evitando conexiones abiertas innecesarias. 
``
import mysql.connector 

conexion = mysql.connector.connect(
    host="localhost",
    user="clientes",
    password="Clientes123$",
    database="clientes"
)

cursor = conexion.cursor()
cursor.execute("SELECT * FROM clientes;")

filas = cursor.fetchall()
print(filas)

cursor.close()
conexion.close()
``

La proyección de campos y la ordenación de resultados permiten mostrar únicamente la información relevante y presentarla de forma clara. Seleccionar solo las columnas necesarias mejora el rendimiento de las consultas y hace el código más legible. Un error frecuente es utilizar SELECT * cuando no es necesario, lo que puede generar consultas más pesadas y difíciles de mantener. Ordenar los resultados directamente en SQL evita tener que hacerlo posteriormente en Python.
``
import mysql.connector 

conexion = mysql.connector.connect(
    host="localhost",
    user="clientes",
    password="Clientes123$",
    database="clientes"
)

cursor = conexion.cursor()
cursor.execute("""
    SELECT
        nombre AS "Nombre del cliente",
        apellidos AS "Apellidos del cliente",
        edad AS "Edad del cliente"
    FROM clientes
    ORDER BY edad DESC;
""")

filas = cursor.fetchall()
print(filas)

cursor.close()
conexion.close()
``

El uso de cursores que devuelven diccionarios facilita el acceso a los datos por nombre de campo, lo que reduce errores y mejora la claridad del código. Esta técnica es especialmente útil cuando se trabaja con muchas columnas o cuando el orden de las mismas puede cambiar. Un fallo habitual es asumir posiciones fijas en listas, lo que puede provocar errores difíciles de detectar si la consulta se modifica.
``
import mysql.connector 

conexion = mysql.connector.connect(
    host="localhost",
    user="clientes",
    password="Clientes123$",
    database="clientes"
)

cursor = conexion.cursor(dictionary=True)
cursor.execute("""
    SELECT
        nombre AS "Nombre del cliente",
        apellidos AS "Apellidos del cliente",
        edad AS "Edad del cliente"
    FROM clientes
    ORDER BY edad DESC;
""")

filas = cursor.fetchall()
print(filas)

cursor.close()
conexion.close()
``

La presentación de los datos recorriendo los resultados como diccionarios permite mostrar la información de forma más clara y comprensible. Separar la lógica de acceso a datos de la lógica de presentación es una buena práctica que facilita el mantenimiento del código. Un error común es mezclar demasiada lógica en un solo bloque, dificultando la lectura y futuras modificaciones.
``
import mysql.connector 

conexion = mysql.connector.connect(
    host="localhost",
    user="clientes",
    password="Clientes123$",
    database="clientes"
)

cursor = conexion.cursor(dictionary=True)
cursor.execute("""
    SELECT
        nombre AS "Nombre del cliente",
        apellidos AS "Apellidos del cliente",
        edad AS "Edad del cliente"
    FROM clientes
    ORDER BY edad DESC;
""")

filas = cursor.fetchall()

for fila in filas:
    print("Nombre:", fila["Nombre del cliente"])
    print("Apellidos:", fila["Apellidos del cliente"])
    print("Edad:", fila["Edad del cliente"])
    print("##################")

cursor.close()
conexion.close()
``
