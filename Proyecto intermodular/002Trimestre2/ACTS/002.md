El uso del formato JSON como medio de intercambio de datos y su lectura tanto desde JavaScript como desde una aplicación web con Flask es otra forma distinta a la base de datos de almacenar y mostrar informacion. El objetivo es entender cómo se consumen datos JSON, cómo se visualizan y cómo se integran en una aplicación cliente-servidor.

La lectura de un archivo JSON local con JavaScript permite familiarizarse con la API fetch, que se utiliza ampliamente para consumir datos externos. Es importante tener en cuenta que fetch funciona correctamente cuando los archivos se sirven desde un servidor (aunque sea local), ya que abrir el HTML directamente con file:// puede provocar errores de CORS. Una buena práctica es revisar siempre la consola del navegador para detectar posibles fallos de carga o rutas incorrectas.
``
<!doctype html>
<html lang="es">
  <head>
    <title>Plantilla fetch</title>
    <meta charset="utf-8">
  </head>
  <body>
    <script>
      fetch("curriculum.json")
        .then(function(respuesta){
          return respuesta.json(); // Convertimos la respuesta a JSON
        })
        .then(function(datos){
          console.log(datos); // Mostramos el contenido en consola
        })
        .catch(function(error){
          console.error("Error al leer el JSON:", error);
        });
    </script>
  </body>
</html>
``

El archivo JSON debe tener una estructura clara y bien formada, ya que cualquier error de sintaxis impedirá su lectura. Una buena práctica es validar el JSON previamente y utilizar nombres de claves descriptivos. Un error común es olvidar comillas o comas, lo que provoca que respuesta.json() falle.
``
{
  "nombre": "Rodrigo",
  "apellidos": "Menendez Molina",
  "correo": "aja@gmail.com"
}
``

La creación de una pequeña aplicación con Flask introduce el concepto de servidor web que entrega contenido dinámico. Flask permite renderizar plantillas HTML y pasarles datos desde Python. Es recomendable mantener separadas las carpetas templates y static para organizar correctamente el proyecto. Un error habitual es no respetar esta estructura, lo que provoca que Flask no encuentre los archivos.
``
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def inicio():
    return render_template("index.html")

if __name__ == "__main__":
    app.run(debug=True)
``

La plantilla HTML utiliza el motor de plantillas Jinja2 para mostrar los datos. Acceder a los valores mediante claves hace el código más legible y fácil de mantener. 
``
<!doctype html>
<html lang="es">
  <head>
    <title>Información Personal</title>
    <meta charset="utf-8">
  </head>
  <body>
    <h1>{{ datos.nombre }}</h1>
    <h2>{{ datos.apellidos }}</h2>
    <h3>{{ datos.correo }}</h3>
  </body>
</html>
``

Como conclusión, esta actividad permite comprender cómo consumir datos JSON desde el lado cliente con JavaScript y cómo servir y mostrar esos mismos datos desde un microservidor con Flask. Estos conocimientos serán fundamentales en futuras aplicaciones web más complejas, como dashboards, APIs REST, aplicaciones SPA o sistemas que consumen datos de servicios externos, donde el uso de JSON y la comunicación entre frontend y backend es una parte esencial del desarrollo profesional.
