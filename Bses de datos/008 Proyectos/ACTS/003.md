El desarrollo de un sistema de noticieros basado en base de datos permite aplicar de forma práctica los conceptos de diseño de bases de datos, relaciones entre tablas y acceso a la información desde PHP. A través de este planteamiento se construye una web sencilla capaz de mostrar noticias almacenadas en una base de datos, relacionando cada noticia con su autor y su fecha de publicación.

Para enpezar crearemos la base de datos y su estructura. Se define una base de datos llamada periodico con dos tablas relacionadas: autores y noticias. La tabla autores almacena la información de los redactores y la tabla noticias guarda los artículos publicados, enlazados mediante una clave foránea que permite asociar cada noticia a su autor correspondiente.
``
CREATE DATABASE periodico
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

USE periodico;

CREATE TABLE autores (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE,
    bio TEXT,
    fecha_registro DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE noticias (
    id INT AUTO_INCREMENT PRIMARY KEY,
    titulo VARCHAR(200) NOT NULL,
    contenido TEXT NOT NULL,
    fecha_publicacion DATETIME DEFAULT CURRENT_TIMESTAMP,
    autor_id INT NULL,
    CONSTRAINT fk_noticias_autores
        FOREIGN KEY (autor_id)
        REFERENCES autores(id)
        ON UPDATE CASCADE
        ON DELETE SET NULL
);
``

Para poder usar la BD necesitamos datos de prueba, tanto para los autores como para las noticias. Esto permite nos comprobar posteriormente que el sistema funciona correctamente y que las relaciones entre tablas están bien definidas.

Otra parte importante es la creación de un usuario específico de MySQL con permisos sobre la base de datos. Este paso es clave para trabajar con buenas prácticas de seguridad y evitar el uso del usuario administrador en aplicaciones web.
``
CREATE USER 'periodico'@'localhost'
IDENTIFIED BY 'Periodico123$';

GRANT ALL PRIVILEGES ON periodico.*
TO 'periodico'@'localhost';

FLUSH PRIVILEGES;
``

En la parte web, el archivo principal index.php se encarga de mostrar la estructura HTML de la página e incluir el archivo que lista las noticias. De este modo se separa la presentación del acceso a datos, facilitando el mantenimiento del código.
``
<!doctype html>
<html lang="es">
  <head>
    <title>La tostada - Noticias tecnológicas</title>
    <meta charset="utf-8">
    <link rel="stylesheet" href="css/estilo.css">
  </head>
  <body>
    <header>
      <h1>La tostada</h1>
      <h2>Noticias tecnológicas</h2>
    </header>
    <main>
      <?php include "inc/listar_articulos.php"; ?>
    </main>
    <footer></footer>
  </body>
</html>
``

La obtención de las noticias se realiza desde el archivo listar_articulos.php, donde se establece la conexión con la base de datos, se ejecuta una consulta y se muestran los resultados dinámicamente en la página web.
``
<?php
$host = "localhost";
$user = "periodico";
$pass = "Periodico123$";
$db   = "periodico";

$conexion = new mysqli($host, $user, $pass, $db);

$sql = "SELECT * FROM noticias";
$resultado = $conexion->query($sql);

while ($fila = $resultado->fetch_assoc()) {
  echo '
    <article>
      <h3>'.$fila['titulo'].'</h3>
      <time>'.$fila['fecha_publicacion'].'</time>
      <p>'.$fila['autor_id'].'</p>
      <p>'.$fila['contenido'].'</p>
    </article>
  ';
}

$conexion->close();
?>
``

Para concluir, esta actividad permite integrar diseño de bases de datos, relaciones entre tablas y programación en PHP para construir un sistema de noticieros funcional. Se refuerza la comprensión de cómo los datos almacenados en una base de datos pueden mostrarse dinámicamente en una página web, sentando las bases para proyectos más complejos con filtros, categorías o gestión de usuarios.
