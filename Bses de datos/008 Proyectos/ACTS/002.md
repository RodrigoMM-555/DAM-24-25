La gestión de bases de datos es una parte esencial en el desarrollo de aplicaciones, ya que permite almacenar, modificar y mantener la información de forma estructurada. A través de esta actividad se trabaja la creación de una base de datos, la asignación de permisos a un usuario y la modificación de registros existentes utilizando SQL y PHP, siguiendo un flujo completo y realista.

Primero, se crea la base de datos y la tabla principal donde se almacenará la información de los empleados. En este caso, la base de datos se llama empleados y contiene una tabla con datos como el nombre, el puesto, el salario, la fecha de contratación y el departamento. Además, se insertan varios registros de ejemplo para poder trabajar posteriormente con ellos y comprobar las modificaciones.
``
CREATE DATABASE IF NOT EXISTS empleados
    DEFAULT CHARACTER SET utf8mb4
    COLLATE utf8mb4_spanish_ci;

USE empleados;

DROP TABLE IF EXISTS empleados;

CREATE TABLE empleados (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    puesto VARCHAR(100) NOT NULL,
    salario DECIMAL(10,2) NOT NULL,
    fecha_contratacion DATE NOT NULL,
    departamento VARCHAR(100)
);

INSERT INTO empleados (nombre, puesto, salario, fecha_contratacion, departamento) VALUES

('Luis Martínez', 'Desarrollador Backend', 32000.00, '2020-11-02', 'IT'),

('Elena García', 'Marketing Specialist', 27000.00, '2021-09-23', 'Marketing');
``

Una vez creada la base de datos, se define un usuario específico que tendrá permisos sobre ella. Este paso es importante para trabajar con seguridad y evitar utilizar el usuario root en aplicaciones reales. El usuario empleados se crea y se le conceden todos los privilegios necesarios sobre la base de datos empleados.
``
CREATE USER 'empleados'@'localhost'
IDENTIFIED BY 'Empleados123$';

GRANT USAGE ON *.* TO 'empleados'@'localhost';

ALTER USER 'empleados'@'localhost'
REQUIRE NONE
WITH MAX_QUERIES_PER_HOUR 0
MAX_CONNECTIONS_PER_HOUR 0
MAX_UPDATES_PER_HOUR 0
MAX_USER_CONNECTIONS 0;

GRANT ALL PRIVILEGES ON empleados.*
TO 'empleados'@'localhost';

FLUSH PRIVILEGES;
``

Con la base de datos y el usuario creadso, pasamos a la parte de modificación de datos mediante PHP. El archivo PHP recibe los datos enviados desde un formulario, establece la conexión con la base de datos y ejecuta una consulta UPDATE para modificar el registro cuyo identificador coincide con el ID recibido. De esta forma, se actualizan los datos del empleado seleccionado.
``
<?php
$nombre = $_POST['nombre'];
$puesto = $_POST['puesto'];
$salario = $_POST['salario'];
$fecha_contratacion = $_POST['fecha_contratacion'];
$departamento = $_POST['departamento'];
$id = $_POST['id'];

$host = "localhost";
$user = "empleados";
$pass = "Empleados123$";
$db   = "empleados";

$conexion = new mysqli($host, $user, $pass, $db);

$sql = "
 UPDATE empleados SET
   nombre = '".$nombre."',
   puesto = '".$puesto."',
   salario = '".$salario."',
   fecha_contratacion = '".$fecha_contratacion."',
   departamento = '".$departamento."'
 WHERE id = ".$id.";
";

$conexion->query($sql);
$conexion->close();
?>
``

Tras ejecutar el script, los cambios se reflejan directamente en la base de datos, permitiendo comprobar cómo se ha modificado el registro correspondiente. Esto ayuda a entender cómo funcionan las actualizaciones de datos desde una aplicación web y cómo se enlazan los formularios con la base de datos.

En conclusión, esta actividad permite practicar de forma completa la creación de una base de datos, la gestión de usuarios y permisos, y la modificación de información mediante consultas SQL ejecutadas desde PHP. Estos conocimientos son fundamentales para el desarrollo de aplicaciones dinámicas y sirven como base para trabajar posteriormente con operaciones más avanzadas como validaciones, seguridad y control de errores.
