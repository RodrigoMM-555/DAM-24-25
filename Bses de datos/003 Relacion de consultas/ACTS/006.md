En esta práctica se aprende a integrar Flask con MySQL y plantillas HTML para mostrar los resultados de consultas que cruzan varias tablas. Se trabaja con una conexión a la base de datos usando mysql.connector y un cursor con dictionary=True, lo que permite acceder a los datos por el nombre de las columnas. Luego, los datos se pasan a una plantilla HTML para mostrarlos en un formato visual atractivo. Esto permite combinar consultas SQL complejas con la presentación dinámica en la web.

Por ejemplo, para obtener los datos de matriculas_join se puede hacer:
``
cursor = conexion.cursor(dictionary=True)
cursor.execute("SELECT * FROM matriculas_join;")
filas = cursor.fetchall()
``

Y en la plantilla HTML se pueden recorrer los resultados así:
``
{% for linea in datos %}
<p>Nombre: {{ linea['Nombre del alumno'] }}</p>
<p>Asignatura: {{ linea['Nombre de la asignatura'] }}</p>
{% endfor %}
``

El código completo de Flask quedaría así:
``
import mysql.connector 
from flask import Flask, render_template

conexion = mysql.connector.connect(
    host="localhost",
    user="composiciones",
    password="composiciones",
    database="composiciones"
)                                      

app = Flask(__name__)

@app.route("/")
def inicio():
    cursor = conexion.cursor(dictionary=True) 
    cursor.execute("SELECT * FROM matriculas_join;")  
    filas = cursor.fetchall()
    cursor.close()
    return render_template("index.html", datos=filas)

if __name__ == "__main__":
    app.run(debug=True)
``

Y la plantilla index.html para mostrar los datos:
``
<!doctype html>
<html lang="es">
  <head>
    <title>Backoffice</title>
    <meta charset="utf-8">
    <style>
      body{font-family:sans-serif;background:aliceblue;}
      header{width:100%;background:indigo;padding:20px;color:white;}
      section{
        margin:auto;display:grid;gap:20px;
        grid-template-columns:repeat(5,100fr);
        padding:20px;
      }
      article{border:1px solid indigo;padding:20px;background:white;
        border-radius:20px;display:flex;gap:20px;align-items:center;}
      .imagen{width:100px;height:100px;background:lightgrey;border-radius:5px;
      overflow:hidden;}
      article img{width:100%;}
    </style>
  </head>
  <body>
    <header><h1>Gestión de escuela</h1></header>
    <main>
      <section>
        {% for linea in datos %}
        <article>
            <div class="imagen">
            	<img src="static/josevicente.jpg">
            </div>
            <div class="texto">
              <p>Asignatura: {{linea['Nombre de la asignatura']}}</p>
              <p>Nombre: {{linea['Nombre del alumno']}}</p>
              <p>Apellidos: {{linea['Apellidos del alumno']}}</p>
            </div>
        </article>
        {% endfor %}
      </section>    
    </main>
  </body>
</html>
``

Como conclusión, esta práctica permite combinar consultas SQL complejas con Flask y plantillas HTML para mostrar los datos de manera visual y estructurada, reforzando los conceptos de cursores con diccionarios y renderizado dinámico. Este enfoque se puede aplicar a cualquier base de datos para crear aplicaciones web interactivas y paneles de gestión.
