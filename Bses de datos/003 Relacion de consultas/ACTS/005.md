En esta práctica se aprende a crear endpoints en Flask que interactúan con una base de datos MySQL. Se trabaja con la conexión a la base de datos mediante mysql.connector y se gestionan consultas SQL dentro de los endpoints para devolver resultados en formato JSON. Esto permite que una aplicación web pueda acceder de forma dinámica a los datos almacenados en la base de datos.

Ejemplo de endpoint que devuelve todos los clientes:
``
@app.route("/clientes")
def clientes():
    cursor = conexion.cursor()
    cursor.execute("SELECT * FROM clientes;")
    filas = cursor.fetchall()
    cursor.close()
    return json.dumps(filas)
``

Ejemplo de endpoint que devuelve la lista de tablas de la base de datos:
``
@app.route("/tablas")
def tablas():
    cursor = conexion.cursor()
    cursor.execute("SHOW TABLES;")
    filas = cursor.fetchall()
    cursor.close()
    
    tablas = [fila[0] for fila in filas]
    return json.dumps(tablas)
``

Código completo de endpoint.py:
``
import mysql.connector 
from flask import Flask, render_template
import json

conexion = mysql.connector.connect(
    host="localhost",
    user="tiendaclase",
    password="Tiendaclase123$",
    database="tiendaclase"
)

app = Flask(__name__)

@app.route("/")
def raiz():
    return render_template("index.html")

@app.route("/clientes")
def clientes():
    cursor = conexion.cursor()
    cursor.execute("SELECT * FROM clientes;")
    filas = cursor.fetchall()
    cursor.close()
    return json.dumps(filas)

@app.route("/tablas")
def tablas():
    cursor = conexion.cursor()
    cursor.execute("SHOW TABLES;")
    filas = cursor.fetchall()
    cursor.close()
    
    tablas = [fila[0] for fila in filas]
    return json.dumps(tablas)

if __name__ == "__main__":
    app.run(debug=True, use_reloader=False)
``

Como conclusión, esta práctica refuerza cómo integrar Flask y MySQL, permitiendo crear endpoints que devuelven datos dinámicamente en formato JSON. Esta habilidad es clave para desarrollar aplicaciones web interactivas que necesiten acceder a información almacenada en bases de datos, y sienta la base para implementar futuras funcionalidades, como filtrado, búsqueda o APIs más completas.
