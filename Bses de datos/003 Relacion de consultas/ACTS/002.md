En este ejercicio se practican los operadores aritméticos, comparativos y lógicos aplicados a consultas SQL en MySQL sobre la base de datos clientes. El objetivo es aprender a realizar cálculos directamente en las consultas, filtrar resultados mediante condiciones y mejorar la legibilidad de los datos usando alias, todo ello sin modificar los valores almacenados en la base de datos.

Para comenzar, es necesario conectarse al gestor MySQL desde el terminal e indicar la base de datos con la que se va a trabajar. Una vez seleccionada la base de datos clientes, ya se pueden ejecutar las consultas correspondientes.

Los operadores aritméticos permiten realizar cálculos sobre los valores de las columnas. Por ejemplo, se puede sumar, restar, multiplicar o dividir la edad de cada cliente directamente en la consulta para mostrar un resultado calculado.
``
SELECT nombre, apellidos, edad + 500
FROM clientes;

SELECT nombre, apellidos, edad - 500
FROM clientes;

SELECT nombre, apellidos, edad * 500
FROM clientes;

SELECT nombre, apellidos, edad / 500
FROM clientes;
``

Estos cálculos no alteran los datos originales, únicamente afectan al resultado mostrado por la consulta. Los operadores aritméticos se pueden combinar con operadores comparativos para filtrar registros. Por ejemplo, se pueden seleccionar solo los clientes mayores de 18 años y aplicar un cálculo sobre su edad.
``
SELECT nombre, apellidos, edad + 500
FROM clientes
WHERE edad > 18;
``

El uso de alias permite asignar nombres más descriptivos a las columnas resultantes, haciendo que la información sea más clara y comprensible para el usuario final.
``
SELECT nombre, apellidos, edad * 2 AS 'Edad Duplicada'
FROM clientes;
``

Además, los operadores lógicos como AND permiten crear condiciones más complejas en la cláusula WHERE, filtrando los resultados según varios criterios al mismo tiempo. Un ejemplo sería seleccionar clientes cuya edad esté dentro de un rango determinado.
``
SELECT nombre, apellidos, edad
FROM clientes
WHERE edad >= 20 AND edad <= 40;
`

Como conclusión, el uso de operadores aritméticos, comparativos y lógicos en MySQL permite realizar consultas mucho más potentes y flexibles, facilitando el análisis de datos sin necesidad de modificar la información almacenada. Estos conceptos son fundamentales para trabajar de forma eficaz con bases de datos y se utilizan constantemente en aplicaciones reales.
