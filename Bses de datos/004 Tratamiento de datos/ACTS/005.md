En esta actividad se practican distintos métodos de codificación, descodificación y hashing, esenciales para la seguridad de contraseñas y datos. Se combinan funciones de Base64, conversiones ASCII, fuerza bruta y algoritmos de hashing para comprender cómo se transforman y protegen los datos.

Por ejemplo, para codificar y descodificar una contraseña con Base64 en PHP:
``
$pass = "contraseñasegura1234";
$codificada = base64_encode($pass);
$descodificada = base64_decode($codificada);
``

Para aplicar codificación y descodificación múltiple, se pueden crear funciones que repitan el proceso 9 veces:
`
function codificar($cadena){
    for($i=0;$i<9;$i++){
        $cadena = base64_encode($cadena);
    }
    return $cadena;
}

function descodificar($cadena){
    for($i=0;$i<9;$i++){
        $cadena = base64_decode($cadena);
    }
    return $cadena;
}
``

Para conversiones ASCII de un carácter:
``
$valor = ord('a');   // convierte 'a' a 97
$char = chr($valor); // convierte 97 de vuelta a 'a'
``

Para hashing con MD5 y SHA1:
``
$md5 = md5("Hola");
$sha1 = sha1("Hola");
``

Como conclusión, estos ejercicios permiten entender y aplicar técnicas de codificación y descodificación, conversiones de caracteres, fuerza bruta y hashing, lo que es fundamental para la seguridad de contraseñas y la protección de datos en cualquier aplicación.
