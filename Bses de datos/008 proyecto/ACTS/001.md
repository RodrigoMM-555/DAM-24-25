El desarrollo de un sistema de login básico permite comprender cómo se relacionan una base de datos, un lenguaje del lado del servidor y la gestión de sesiones. En esta práctica se integran conceptos fundamentales como la creación de bases de datos, el uso de usuarios de MySQL, la validación de credenciales y el control de acceso mediante sesiones en PHP.

Primero debemos crear una base de datos para almacenar la información de los usuarios. Definimos una estructura sencilla, con claves únicas para el usuario y el correo electrónico, lo que garantiza la integridad de los datos y evita duplicados.
``
CREATE DATABASE IF NOT EXISTS superaplicacion
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

USE superaplicacion;

CREATE TABLE IF NOT EXISTS usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    usuario VARCHAR(50) NOT NULL UNIQUE,
    contrasena VARCHAR(255) NOT NULL,
    nombrecompleto VARCHAR(150) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
``

Para poder acceder a la base de datos desde PHP, creamos un usuario con permisos únicamente sobre esta base de datos. Esto es una buena práctica, ya que evita usar el usuario root para aplicaciones web.
``
CREATE USER 'superaplicacion'@'localhost'
IDENTIFIED BY 'Superaplicacion123$';

GRANT ALL PRIVILEGES ON superaplicacion.*
TO 'superaplicacion'@'localhost';

FLUSH PRIVILEGES;
``

Una vez creada la estructura, insertamos datos de prueba en la tabla de usuarios. Con esto comprobaremos si el sistema de login funciona correctamente antes de ampliarlo o modificarlo.
``
INSERT INTO usuarios (usuario, contrasena, nombrecompleto, email)
VALUES ('jlopez', '1234segura', 'Juan López', 'juan.lopez@example.com');
``

La página de login se encarga de recoger las credenciales del usuario. Es un formulario HTML sencillo que envía los datos mediante POST a un archivo PHP encargado de procesarlos.
``
<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <title>Login</title>
  </head>
  <body>
    <form action="procesa.php" method="post">
      <input type="text" name="usuario" placeholder="Usuario" required>
      <input type="password" name="contrasena" placeholder="Contraseña" required>
      <button type="submit">Iniciar sesión</button>
    </form>
  </body>
</html>
``

El archivo que procesa el login establece la conexión con la base de datos, recoge los datos enviados por el formulario y comprueba si existe un usuario con esas credenciales. Si la validación es correcta, se inicia una sesión y se redirige al usuario a la página de éxito.
``
<?php
session_start();

$conexion = new mysqli(
  "localhost",
  "superaplicacion",
  "Superaplicacion123$",
  "superaplicacion"
);

if ($conexion->connect_error) {
  die("Error de conexión");
}

$usuario = $_POST['usuario'];
$contrasena = $_POST['contrasena'];

$sql = "SELECT * FROM usuarios WHERE usuario = ? AND contrasena = ?";
$stmt = $conexion->prepare($sql);
$stmt->bind_param("ss", $usuario, $contrasena);
$stmt->execute();
$result = $stmt->get_result();

if ($result->num_rows > 0) {
  $_SESSION['usuario'] = $usuario;
  header("Location: exito.php");
  exit();
} else {
  echo "Error al iniciar sesión. Verifica tus credenciales.";
}

$stmt->close();
$conexion->close();
?>
``

La página de éxito comprueba que la sesión esté iniciada. Si alguien intenta acceder directamente sin haberse autenticado, el sistema bloquea el acceso mostrando un mensaje de error.
``
<?php
session_start();

if (!isset($_SESSION['usuario'])) {
  die("Te has intentado colar, pero no ha colado");
}
?>
Si estas viendo esto es que has entrado correctamente
``

En conclusión, esta actividad permite entender el funcionamiento completo de un sistema de autenticación básico en PHP y MySQL, desde la creación de la base de datos hasta el control de acceso mediante sesiones. Estos conocimientos son esenciales en el desarrollo web, ya que sirven como base para implementar sistemas más avanzados de seguridad, registro de usuarios y control de permisos en aplicaciones reales.
