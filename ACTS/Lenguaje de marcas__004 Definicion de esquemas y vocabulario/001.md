XML es un lenguaje de marcas diseñado para estructurar, almacenar e intercambiar información de forma clara y jerárquica. Sus elementos principales son las etiquetas definidas por el propio desarrollador, la obligatoriedad de una única etiqueta raíz que contenga todo el documento y el respeto estricto de la sintaxis, ya que distingue entre mayúsculas y minúsculas. Comprender estos conceptos es esencial para definir vocabularios y esquemas correctos dentro de esta unidad.

Uno de los aspectos fundamentales es que todo documento XML debe tener una etiqueta principal que actúe como contenedor del resto del contenido. Aunque no incluya información en su interior, esta etiqueta raíz es obligatoria para que el documento sea válido.
``
<?xml version="1.0" encoding="UTF-8"?>
<persona>
  
</persona>
``

Otro concepto clave es la sensibilidad a mayúsculas y minúsculas. En XML, una etiqueta debe abrirse y cerrarse exactamente con el mismo nombre. Si se utiliza una combinación distinta de letras mayúsculas y minúsculas, el documento se considera incorrecto desde el punto de vista sintáctico.
``
<?xml version="1.0" encoding="UTF-8"?>
<persona>
  
</Persona>
``

También es importante aprender a organizar la información mediante subetiquetas, creando una estructura lógica y jerárquica. En este caso, una etiqueta principal agrupa los datos básicos de una persona mediante etiquetas internas que representan cada campo necesario.
``
<?xml version="1.0" encoding="UTF-8"?>
<persona>
  <nombre>Jose Vicente</nombre>
  <apellidos>Carratala Sanchis</apellidos>
</persona>
``

Finalmente, se puede ampliar esta estructura para representar múltiples valores de un mismo tipo de dato. Para ello, se utiliza una etiqueta contenedora que agrupa varias etiquetas repetidas, permitiendo almacenar listas de información, como varios números de teléfono asociados a una misma persona.
``
<?xml version="1.0" encoding="UTF-8"?>
<persona>
  <nombre>Jose Vicente</nombre>
  <apellidos>Carratala Sanchis</apellidos>
  <telefonos>
    <telefono>12345567</telefono>
    <telefono>6534646</telefono>
  </telefonos>
</persona>
``

Como conclusión, dominar la estructura básica de XML permite crear documentos bien formados y fáciles de interpretar, sentando las bases para trabajar en proyectos más avanzados como la validación mediante esquemas XML o el intercambio de datos entre aplicaciones. Estos conocimientos serán especialmente útiles en futuros desarrollos donde sea necesario definir formatos de datos personalizados y robustos.
