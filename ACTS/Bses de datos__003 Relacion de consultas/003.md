En este ejercicio se trabajan las consultas de resumen en SQL utilizando funciones de agregación y redondeo sobre la base de datos clientes, así como su aplicación práctica desde Python para el análisis de datos.

Para calcular el promedio redondeado de las edades de los clientes se combinan las funciones AVG y ROUND, obteniendo un valor más legible.
``
SELECT ROUND(AVG(edad)) AS 'Edad media'
FROM clientes;
``

Para obtener el cliente más joven se utiliza la función MIN junto con una subconsulta que permite mostrar sus datos completos.
``
SELECT nombre, apellidos, edad
FROM clientes
WHERE edad = (SELECT MIN(edad) FROM clientes);
``

El cliente más viejo se identifica ordenando los registros por edad de forma descendente y limitando el resultado a un solo registro.
``
SELECT nombre, apellidos, edad
FROM clientes
ORDER BY edad DESC
LIMIT 1;
``

Finalmente, los datos obtenidos se pueden usar desde Python para generar una gráfica circular que represente las edades de los clientes agrupadas en rangos.
``
import matplotlib.pyplot as pt

pt.pie([40, 30, 20, 10])
pt.show()
``

Como conclusión, las consultas de resumen permiten obtener información global de forma sencilla y clara, y combinadas con Python facilitan el análisis y la visualización de los datos almacenados en la base de datos.
