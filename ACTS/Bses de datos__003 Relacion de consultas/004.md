En esta actividad se combinan consultas SQL de agrupamiento con visualización en Python. Se trabaja con una conexión a la base de datos y un cursor para ejecutar las consultas, mientras que SQL permite agrupar y ordenar registros (por categoría, color o stock) usando GROUP BY y ORDER BY. Finalmente, matplotlib se utiliza para representar los resultados en gráficas claras y visuales.

Algunos ejejmplos de como agrupar y contar registros en mysql serian estos:
``
-- Contar productos por categoría y ordenar descendente
SELECT COUNT(categoria) AS numero, categoria
FROM productos
GROUP BY categoria
ORDER BY numero DESC;

-- Contar productos por color y ordenar ascendente
SELECT COUNT(color) AS numero, color
FROM productos
GROUP BY color
ORDER BY numero ASC;

-- Contar productos por stock
SELECT COUNT(stock) AS numero, stock
FROM productos
GROUP BY stock
ORDER BY stock DESC;
``

Y aqui un ejejmplo de gráfico en Python:
``
import matplotlib.pyplot as pt

#Gráfica simple de ejemplo
pt.bar(['A', 'B', 'C'], [10, 20, 15])
pt.show()
``

El codigo final uniendo todo lo mostrado quedaria asi:
``
import mysql.connector
import matplotlib.pyplot as pt

#Conexión a la base de datos
conexion = mysql.connector.connect(
    host="localhost",
    user="clientes",
    password="Clientes123$",
    database="clientes"
)

cursor = conexion.cursor()

#Consulta SQL: productos por categoría
cursor.execute('''
    SELECT COUNT(categoria) AS numero, categoria
    FROM productos
    GROUP BY categoria
    ORDER BY numero DESC;
''')

#Procesar resultados
filas = cursor.fetchall()
cantidades = []
etiquetas = []

for fila in filas:
    cantidades.append(fila[0])
    etiquetas.append(fila[1])

#Gráfico de barras
pt.bar(etiquetas, cantidades)
pt.xlabel('Categoría')
pt.ylabel('Cantidad de Productos')
pt.title('Productos por Categoría')
pt.show()

#Cerrar conexión
cursor.close()
conexion.close()
``

En conclusión, combinar SQL con Python permite analizar y visualizar datos de forma clara, reforzando lo aprendido con proyecciones, ordenaciones y resúmenes. Esta técnica se puede aplicar a cualquier tipo de análisis en bases de datos, dejandonos en el futuro crear proyectos más avanzados de visualización y toma de decisiones basada en datos.
