En este ejercicio se continúa trabajando con Flask, centrándose en la lectura de parámetros enviados a través de la URL. Este mecanismo es muy habitual en aplicaciones web para recibir datos del usuario sin necesidad de formularios complejos, por lo que resulta importante entender cómo se recogen y se usan dentro de las rutas.

El primer paso consiste en comprobar que el servidor básico funciona correctamente. Este archivo sirve como punto de partida para asegurarse de que Flask está bien instalado y que la aplicación responde al acceder a la ruta raíz. Es importante revisar con calma los imports, ya que un pequeño error tipográfico puede impedir que el servidor arranque correctamente.
``
from flask import Flask, request

app = Flask(__name__)

@app.route("/")
def inicio():
    return "Servidor Flask en funcionamiento"

if __name__ == "__main__":
    app.run(debug=True)
``

A continuación se trabaja con un microformulario que recoge parámetros desde la URL. En este caso, la ruta /envio obtiene el nombre y los apellidos usando request.args.get() y los muestra por consola. Esto permite comprobar desde el propio servidor que los datos realmente están llegando. Resulta útil observar la terminal mientras se hacen peticiones desde el navegador para verificar el comportamiento del servidor.
``
from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/")
def inicio():
    return render_template("index.html")

@app.route("/envio")
def envio():
    nombre = request.args.get("nombre")
    apellidos = request.args.get("apellidos")
    print(nombre, apellidos)
    return "Mira en la consola si ha pasado algo"

if __name__ == "__main__":
    app.run(debug=True)
``

Al acceder a una URL como
http://127.0.0.1:5000/envio?nombre=Jose&apellidos=Vicente
los valores enviados aparecen en la consola del servidor, lo que confirma que los parámetros han sido procesados correctamente.

En el siguiente archivo se da un paso más y, en lugar de limitarse a imprimir los datos, se devuelven directamente al navegador. Esto permite comprobar cómo Flask puede construir respuestas dinámicas a partir de la información recibida en la URL. Conviene tener cuidado al concatenar valores, ya que si alguno de los parámetros no llega, el servidor podría mostrar un error.
``
from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/")
def inicio():
    return render_template("index.html")

@app.route("/envio")
def envio():
    nombre = request.args.get("nombre")
    apellidos = request.args.get("apellidos")
    return "nombre: " + nombre + " - apellidos: " + apellidos

if __name__ == "__main__":
    app.run(debug=True)
``

Al visitar la misma URL con distintos valores, el mensaje cambia dinámicamente, demostrando que el servidor es capaz de manejar diferentes parámetros sin modificar el código.

Para cerrar la actividad, este ejercicio permite comprender cómo Flask gestiona los datos enviados por la URL y cómo se pueden utilizar tanto para depuración en consola como para generar respuestas personalizadas. Estos conocimientos serán especialmente útiles en desarrollos futuros como formularios web, filtros de búsqueda, enlaces dinámicos o incluso APIs sencillas, donde la lectura y validación de parámetros es una parte esencial del funcionamiento de la aplicación.
