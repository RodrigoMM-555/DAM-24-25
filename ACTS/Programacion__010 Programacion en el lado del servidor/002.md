GET y POST son los verbos HTTP más utilizados para intercambiar información entre el navegador y el servidor. GET se emplea para recuperar datos, mientras que POST se utiliza para enviar información que será procesada o almacenada. Comprender la diferencia entre ambos es esencial para enviar y recibir datos de forma segura y estructurada en aplicaciones web.

Primero, creamos un formulario HTML con dos campos: uno para la pregunta y otro para la respuesta. El formulario utiliza el método POST, lo que permite enviar los datos de manera segura al servidor sin que aparezcan en la URL.
``
<!doctype html>
<html>
<head>
    <style>
        body, html { width:100%; height:100%; padding:0; margin:0; }
        body { display:flex; flex-direction:column; align-items:center; justify-content:center; background:lightgray; }
        header, main, footer { width:400px; padding:20px; background:white; text-align:center; }
        form { display:flex; flex-direction:column; gap:10px; }
        input { padding:10px; }
    </style>
</head>
<body>
    <header>
        <h1>Preguntas y respuestas</h1>
    </header>
    <main>
        <form action="procesar.php" method="POST">
            <label for="pregunta">Introduce la pregunta</label>
            <input type="text" name="pregunta" id="pregunta">
            <label for="respuesta">Introduce la respuesta</label>
            <input type="text" name="respuesta" id="respuesta">
            <input type="submit" value="Enviar">
        </form>
    </main>
</body>
</html>
``

En el archivo procesar.php, procesamos los datos enviados usando  $_POST . Antes de mostrar la información, comprobamos que ambos campos existen con isset() para evitar errores si alguien accede directamente al archivo sin enviar el formulario.
``
<?php
if(isset($_POST['pregunta']) && isset($_POST['respuesta'])){
    $pregunta = $_POST['pregunta'];
    $respuesta = $_POST['respuesta'];
    echo "<h2>Pregunta:</h2> " . htmlspecialchars($pregunta) . "<br>";
    echo "<h2>Respuesta:</h2> " . htmlspecialchars($respuesta);
} else {
    echo "No se han enviado datos todavía.";
}
?>
``

Al enviar el formulario, los datos se reciben correctamente en el servidor y se muestran en la página de procesamiento, demostrando cómo POST permite enviar información de manera segura y cómo verificar la existencia de los datos antes de utilizarlos.

En conclusión, hemos aprendido cómo usar los verbos HTTP GET y POST para enviar y recibir datos entre cliente y servidor, y la importancia de validar la existencia de los datos antes de procesarlos. En un futuro esto ayudara a manejar la información de forma segura y estructurada, mejorando la eficiencia y la robustez del código en aplicaciones web.
