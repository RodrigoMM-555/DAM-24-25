En este ejercicio se trabaja el movimiento de personajes dentro de un plano bidimensional, algo muy habitual en el desarrollo de videojuegos. A partir de un contexto cercano para el alumnado, como es el ocio digital, se introducen conceptos matemáticos y de programación que permiten simular comportamientos realistas, como el movimiento continuo y el cambio de dirección de los NPCs.

En este ejemplo se amplía la clase Npc para que cada personaje tenga una velocidad propia y un método mover() más completo. La posición del NPC se actualiza usando funciones trigonométricas (cos y sin) en función de su dirección y velocidad. Además, de forma aleatoria, el NPC puede cambiar su dirección para simular un movimiento impredecible, lo que hace el comportamiento más natural y divertido.
``
import random
import json
from flask import Flask, render_template
import math  # Para poder hacer trigonometría

class Npc():
    def __init__(self, x, y, radio, direccion, velocidad):
        self.posx = x
        self.posy = y
        self.radio = radio
        self.direccion = direccion
        self.velocidad = velocidad  # NUEVO

    def to_dict(self):
        return {
            "posx": self.posx,
            "posy": self.posy,
            "radio": self.radio,
            "direccion": self.direccion
        }

    def mover(self):
        # Actualiza la posición usando trigonometría
        self.posx += math.cos(self.direccion) * self.velocidad
        self.posy += math.sin(self.direccion) * self.velocidad

        # Cambio aleatorio de dirección
        if random.random() < 0.05:
            self.direccion = random.random() * math.pi * 2

#Preparo los personajes
personajes = []
numero_personajes = 50

for i in range(numero_personajes):
    xaleatoria = random.randint(0, 500)
    yaleatoria = random.randint(0, 500)
    radioaleatorio = random.randint(10, 30)
    direccionaleatoria = random.random() * math.pi * 2
    velocidadaleatoria = random.uniform(0.5, 3)

    personajes.append(
        Npc(xaleatoria, yaleatoria, radioaleatorio, direccionaleatoria, velocidadaleatoria)
    )

#Lanzo una web
app = Flask(__name__)

@app.route("/")
def inicio():
    return render_template("juego.html")

@app.route("/api")
def api():
    for personaje in personajes:
        personaje.mover()
    personajes_json = [p.to_dict() for p in personajes]
    return json.dumps(personajes_json, indent=2)

if __name__ == "__main__":
    app.run(debug=True)
``

Con esta práctica se refuerza el uso de la trigonometría aplicada a un problema real, entendiendo cómo calcular desplazamientos en dos dimensiones. Además, se trabaja la actualización de objetos en el tiempo y la comunicación de datos mediante una API para su visualización en un navegador, conceptos clave dentro de la unidad y fundamentales en el desarrollo de aplicaciones y videojuegos modernos.
