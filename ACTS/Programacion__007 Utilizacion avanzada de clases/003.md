En este ejercicio el objetivo principal es trabajar la jerarquía de clases y la herencia en programación orientada a objetos, aplicándolas a un ejemplo visual y sencillo. A través de una clase base y varias clases derivadas, se busca entender cómo compartir propiedades comunes, cómo extender comportamientos y cómo usar esa información para controlar el movimiento y las restricciones dentro de un espacio definido.

Primero se plantea una clase base llamada Película, que actúa como elemento común del sistema. Esta clase define las características generales del espacio donde ocurre la acción, como el ancho y el alto de la habitación. Estas propiedades serán heredadas por las demás clases, permitiendo que conozcan los límites del entorno sin necesidad de duplicar información.
``
<!doctype html>
<html>
  <head>
    <style>
      body{
        margin:0;
        overflow:hidden;
      }
      #habitacion{
        position:relative;
        background:#444;
      }
      .actor{
        position:absolute;
        width:40px;
        height:40px;
        background:blue;
      }
      .silla{
        position:absolute;
        width:40px;
        height:40px;
        background:brown;
      }
    </style>
  </head>
  <body>
    <div id="habitacion"></div>
  </body>
  <script>
    class Pelicula{
      constructor(ancho, alto){
        this.ancho = ancho;
        this.alto = alto;
      }
    }
``

A partir de esta clase base se define la clase Actor, que hereda de Película. Además de las propiedades heredadas, se añaden atributos propios como la posición y la velocidad. El método mover() utiliza estos datos junto con los límites heredados para decidir si el actor puede desplazarse o no dentro de la habitación, reforzando la idea de reutilización de código.
``
    class Actor extends Pelicula{
      constructor(ancho, alto, x, y, velocidad){
        super(ancho, alto);
        this.x = x;
        this.y = y;
        this.velocidad = velocidad;
      }

      mover(dx, dy){
        let nuevaX = this.x + dx * this.velocidad;
        let nuevaY = this.y + dy * this.velocidad;

        if(nuevaX >= 0 && nuevaX <= this.ancho - 40){
          this.x = nuevaX;
        }
        if(nuevaY >= 0 && nuevaY <= this.alto - 40){
          this.y = nuevaY;
        }
      }
    }
``

Después se incorpora la clase Silla, que también hereda de Película. En este caso no necesita velocidad ni movimiento, pero sí conocer el tamaño de la habitación para situarse correctamente dentro de ella. Esto muestra cómo distintas clases pueden compartir una misma base aunque su comportamiento sea diferente.
``
    class Silla extends Pelicula{
      constructor(ancho, alto, x, y){
        super(ancho, alto);
        this.x = x;
        this.y = y;
      }
    }
``

Finalmente se crean las instancias y se conectan con el teclado para probar el funcionamiento. El actor se mueve usando las teclas WASD, y cada desplazamiento pasa por el método mover(), que comprueba las restricciones del espacio antes de actualizar la posición. Los objetos se representan mediante elementos HTML, mientras que su lógica se controla desde JavaScript.
``
    let anchoPantalla = window.innerWidth;
    let altoPantalla = window.innerHeight;

    let habitacion = document.querySelector("#habitacion");
    habitacion.style.width = anchoPantalla+"px";
    habitacion.style.height = altoPantalla+"px";

    let actor = new Actor(anchoPantalla, altoPantalla, 100, 100, 5);
    let divActor = document.createElement("div");
    divActor.classList.add("actor");
    habitacion.appendChild(divActor);

    let silla = new Silla(anchoPantalla, altoPantalla, 300, 300);
    let divSilla = document.createElement("div");
    divSilla.classList.add("silla");
    divSilla.style.left = silla.x+"px";
    divSilla.style.top = silla.y+"px";
    habitacion.appendChild(divSilla);

    document.onkeydown = function(e){
      switch(e.keyCode){
        case 87: actor.mover(0,-1); break;
        case 83: actor.mover(0,1); break;
        case 65: actor.mover(-1,0); break;
        case 68: actor.mover(1,0); break;
      }
      divActor.style.left = actor.x+"px";
      divActor.style.top = actor.y+"px";
    }
  </script>
</html>
``

En conclusion, la clase base puede servir como punto común para distintos tipos de objetos con comportamientos diferentes. A partir de lo aprendido, el sistema puede ampliarse fácilmente añadiendo nuevas entidades, incorporando colisiones, animaciones o reglas más complejas de movimiento, lo que demuestra cómo esta estructura es una base sólida para futuros desarrollos en videojuegos y aplicaciones interactivas.
