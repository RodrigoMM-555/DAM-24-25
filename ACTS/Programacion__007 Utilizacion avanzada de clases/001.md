En este ejercicio se trabaja el concepto de herencia para evitar duplicar código y para organizar mejor la información común y la específica de cada tipo de usuario. La clase Persona actúa como base común, mientras que Profesor y Alumno representan especializaciones de esa persona dentro del sistema.

Para empezar tenemos que definir la clase Persona, que contiene los atributos comunes a cualquier usuario del sistema: nombre, apellidos, email y dirección. El constructor se encarga de inicializar estos datos cuando se crea un objeto, y el método dameDatos() devuelve el nombre completo, lo que permite reutilizar este comportamiento tanto en profesores como en alumnos sin necesidad de reescribirlo.
``
class Persona:
    def __init__(self, nombre, apellidos, email, direccion):
        self.nombre = nombre
        self.apellidos = apellidos
        self.email = email
        self.direccion = direccion

    def dameDatos(self):
        return self.nombre + " " + self.apellidos
``

A continuación se crea la clase Profesor, que hereda de Persona. En su constructor se llama al constructor de la clase padre usando super().__init__(), lo que garantiza que los atributos comunes se inicialicen correctamente. Se puede añadir algún atributo propio del profesor, como por ejemplo la asignatura que imparte, para diferenciarlo del resto de personas del sistema.
``
class Profesor(Persona):
    def __init__(self, nombre, apellidos, email, direccion, asignatura):
        super().__init__(nombre, apellidos, email, direccion)
        self.asignatura = asignatura

    def dameAsignatura(self):
        return self.asignatura
``

De forma similar, se define la clase Alumno, que también hereda de Persona. De nuevo se reutiliza el constructor de la clase base y se añade un atributo específico, como puede ser el curso en el que está matriculado el alumno. Esto demuestra cómo la herencia permite extender la funcionalidad sin romper la estructura común.
``
class Alumno(Persona):
    def __init__(self, nombre, apellidos, email, direccion, curso):
        super().__init__(nombre, apellidos, email, direccion)
        self.curso = curso

    def dameCurso(self):
        return self.curso
``

Por último, se crean instancias reales de Profesor y Alumno para comprobar el funcionamiento del sistema. Se utilizan los datos de cada objeto y se imprime el resultado del método dameDatos(), demostrando que ambos, aunque sean clases distintas, comparten el mismo comportamiento heredado de Persona.
``
profesor1 = Profesor(
    "Rodrigo",
    "Menéndez",
    "rodrigo@email.com",
    "Calle Mayor 1",
    "Programación"
)

alumno1 = Alumno(
    "Ana",
    "García",
    "ana@email.com",
    "Avenida Central 3",
    "2º DAM"
)

print(profesor1.dameDatos())
print(alumno1.dameDatos())
``

En conclusión, la herencia facilita la organización del código y la gestión de distintos tipos de usuarios dentro de un mismo sistema. Al definir una clase base con los atributos y métodos comunes, se reduce la duplicación y se mejora la claridad del programa. Este enfoque es fundamental en programación orientada a objetos y sienta las bases para desarrollar aplicaciones más grandes y mantenibles a lo largo de la unidad.
